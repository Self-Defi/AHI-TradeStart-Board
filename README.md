# AHI TradeStart Opportunity Board

Mobile-friendly **fictional-data** prototype. One trainee per shift by default; job details may specify more. Includes AHI Admin, Participant View, and Training History.

## Activate GitHub Pages
Repository **Settings → Pages → Build and deployment → GitHub Actions**. The workflow under `.github/workflows/pages.yml` handles the rest, subject to Pages eligibility for this repository's visibility and account plan.

No real trainees, customers or employment offers. No shared database or access control. Browser-local demo data is not synchronized. Do not enter personally identifiable applicant information.
